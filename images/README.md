# 사진 넣는 곳

아래 파일명으로 이 폴더에 사진을 넣으면 페이지에 자동으로 반영됩니다.
파일이 없으면 해당 자리에 짙은 남색 플레이스홀더가 표시됩니다.

| 파일명 | 위치 | 권장 사이즈 / 비율 |
| --- | --- | --- |
| `hero.jpg` | 첫 화면 배경 | 2400×1350 (16:9) 가로 |
| `course-experience.jpg` | 프로그램 · 체험 다이빙 | 900×1200 (3:4) 세로 |
| `course-scuba.jpg` | 프로그램 · 스쿠버 자격증 교육 | 900×1200 (3:4) 세로 |
| `course-culture.jpg` | 프로그램 · 문화 해설 다이빙 | 900×1200 (3:4) 세로 |
| `course-science.jpg` | 프로그램 · 시민과학 · 해양환경 | 900×1200 (3:4) 세로 |
| `about.jpg` | 소개 섹션 | 1600×1200 (4:3) 가로 |
| `instructor.jpg` | 강사 소개 | 1000×1250 (4:5) 세로 |
| `contact.jpg` | 문의 배너 배경 | 2400×1000 가로, 어두운 사진 권장 |

- 형식은 `.jpg` 기준입니다. `.webp`를 쓰려면 `index.html`의 `src` 확장자도 함께 바꿔 주세요.
- 히어로와 문의 배너는 위에 흰 글씨가 올라가므로 너무 밝은 사진은 피해 주세요.
- 각 사진은 2MB 이하로 줄여서 넣는 것을 권합니다.
