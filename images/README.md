# 사진 넣는 곳

이 폴더에 아래 파일명으로 사진을 넣으면 페이지에 자동 반영됩니다.
파일이 없는 자리는 짙은 남색 패널(로고 마크)로 표시되므로 사진 없이도 페이지는 정상 동작합니다.

| 파일명 | 위치 | 권장 비율 |
| --- | --- | --- |
| `hero.jpg` | 첫 화면 배경 | 16:9 가로, 2400px 이상 |
| `course-experience.jpg` | 프로그램 · 체험 다이빙 | 3:4 세로 |
| `course-scuba.jpg` | 프로그램 · 스쿠버 자격증 교육 | 3:4 세로 |
| `course-culture.jpg` | 프로그램 · 문화 해설 다이빙 | 3:4 세로 |
| `course-science.jpg` | 프로그램 · 시민과학 · 해양환경 | 3:4 세로 |
| `about.jpg` | 소개 섹션 | 4:3 가로 |
| `instructor.jpg` | 강사 소개 | 4:5 세로 |
| `contact.jpg` | 문의 배너 배경 | 16:9 가로, 어두운 사진 |

- 히어로와 문의 배너는 흰 글씨가 올라가므로 어두운 사진이 좋습니다.
- 각 파일은 300KB 이하로 압축해서 넣는 것을 권합니다.
- `.webp`나 `.png`를 쓰려면 `index.html`의 `src` 확장자도 함께 바꿔 주세요.
